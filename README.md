# Student Performance Prediction System

## Project Overview
The Student Performance Prediction System is a Machine Learning-based project that predicts a student's final grade using academic information such as study time, number of absences, and previous period grades.

The project uses a Random Forest Regressor trained on student performance data.

## Objectives
- Predict students' final grades using Machine Learning.
- Understand the relationship between academic factors and student performance.
- Provide a simple web interface for entering student details and viewing predictions.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Joblib
- HTML and CSS

## Dataset
The project uses the Student Performance dataset (`student-mat.csv`), containing student academic and personal information. The model uses these features:
- Study time
- Number of absences
- First period grade (G1)
- Second period grade (G2)

The target variable is the final grade (G3).

## Machine Learning Algorithm
A Random Forest Regressor is used to predict the final grade.

The model is trained using `train_model.py` and saved as `model.pkl`. The Flask application loads this trained model to generate predictions.

## Project Files
- `app.py` — Flask web application.
- `train_model.py` — Code for training and evaluating the model.
- `model.pkl` — Saved trained Machine Learning model.
- `student-mat.csv` — Dataset used for training.
- `requirements.txt` — Required Python packages.
- `README.md` — Project documentation.

## How to Run the Project

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required packages:

   `py -m pip install -r requirements.txt`

5. Train the model if needed:

   `py train_model.py`

6. Start the web application:

   `py app.py`

7. Open `http://127.0.0.1:5000` in your browser.

## Model Evaluation
The model was evaluated using Mean Absolute Error (MAE) and R-squared (R²).

In the current local training run:
- Mean Absolute Error: approximately 1.11
- R-squared Score: approximately 0.84

Results may vary if the dataset or training configuration changes.

## Disclaimer
The predicted grade is an estimate generated by a Machine Learning model. It should not be treated as a guaranteed final result.
